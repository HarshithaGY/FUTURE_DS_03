# Future DS 03 – Bank Marketing Campaign Analysis

## Project Overview
This project analyzes bank marketing campaign data to understand customer subscription behavior and campaign performance.

## Objectives
- Analyze the number of customers contacted.
- Measure successful term-deposit subscriptions.
- Calculate the overall conversion rate.
- Compare subscription outcomes across job and education categories.
- Explore the outcomes of previous marketing campaigns.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## Key Performance Indicators
- Total Customers: 4,521
- Successful Subscriptions: 521
- Conversion Rate: 11.52%

## Dashboard Insights
- The dashboard compares successful subscriptions across job categories.
- Education categories are compared by successful subscription counts.
- Previous campaign outcomes are analyzed to explore their relationship with subscription success.
